# Lógica de Programação na Prática

## Objetivo

Introduzir os conceitos fundamentais de lógica de programação e ensinar, de forma prática e gradual, como transformar problemas simples em algoritmos e soluções estruturadas.

## Público-alvo

Iniciantes em programação que possuem pouco ou nenhum conhecimento sobre lógica de programação.

## Pré-requisitos

Não é necessário possuir conhecimento prévio em programação. É recomendado ter familiaridade básica com o uso de computadores e disposição para resolver exercícios práticos.

## Estrutura

O guia está dividido em módulos que apresentam os conceitos de forma gradual:

1. [Introdução](docs/01-introducao.md)
2. [Conceitos fundamentais](docs/02-conceitos.md)
3. [Exercícios](docs/03-exercicios.md)
4. [Referências](docs/04-referencias.md)

Exemplos práticos podem ser encontrados na pasta [exemplos](exemplos/).

## Como navegar

Recomenda-se seguir os módulos na ordem apresentada, começando pela introdução e avançando gradualmente para os conceitos e exercícios.
