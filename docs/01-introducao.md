# 1. Introdução à Lógica de Programação

## O que é programação?

Programação é o processo de criar instruções para que um computador realize determinadas tarefas. Um programa é formado por uma sequência de instruções que o computador consegue interpretar e executar.

## O que é lógica de programação?

Lógica de programação é a maneira de organizar o raciocínio para encontrar uma solução para determinado problema. Antes de escrever código, é importante entender o problema e definir quais passos precisam ser realizados para resolvê-lo.

## O que é um algoritmo?

Um algoritmo é uma sequência organizada de passos utilizada para resolver um problema ou realizar uma tarefa. Um exemplo simples do cotidiano é preparar um café:

1. Colocar água para aquecer.
2. Preparar o café.
3. Adicionar a água quente.
4. Aguardar alguns minutos.
5. Servir.

Na programação, fazemos algo semelhante: dividimos um problema em passos que possam ser executados de maneira organizada.

## Do problema ao algoritmo

Para resolver um problema utilizando programação, podemos seguir uma sequência:

**Problema → Análise → Algoritmo → Implementação → Teste**

Primeiro entendemos o problema. Depois pensamos em uma solução, organizamos essa solução em passos e por fim, podemos transformá-la em código.

## Exercício

Pense em uma tarefa cotidiana, como escovar os dentes ou preparar um sanduíche. Escreva pelo menos cinco passos necessários para realizar essa tarefa na ordem correta.

### Desafio

Imagine que você precisa criar um programa que calcule a média de duas notas. Antes de escrever qualquer código, responda:

- Quais informações o programa precisa receber?
- Qual cálculo precisa ser realizado?
- Qual resultado deve ser apresentado?
