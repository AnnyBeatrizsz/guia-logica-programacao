# Aprendizados

## O que aprendi

Durante a construção deste projeto, pratiquei o uso do Git e do GitHub para organizar e versionar um projeto de forma estruturada. Aprendi a criar branches para separar diferentes partes do desenvolvimento, realizar commits atômicos e utilizar mensagens padronizadas para facilitar a compreensão do histórico. Também pratiquei o envio de branches para o GitHub e a criação de Pull Requests para propor alterações à branch principal.

## Pull Request

O Pull Request foi utilizado para revisar e integrar as alterações da branch `feature/exercicios` à `main`. A descrição do Pull Request apresentou o que foi desenvolvido, como a revisão poderia ser realizada e um checklist para verificar o estado da alteração.

## Conflitos

Também pratiquei a criação e resolução de um conflito controlado entre branches. A resolução exigiu identificar as alterações conflitantes, analisar as duas versões e escolher uma solução coerente antes de concluir o merge.

## Histórico

O uso de commits menores e descritivos tornou o histórico do projeto mais fácil de compreender e permitiu identificar quais alterações foram realizadas em cada etapa.

## Conclusão

O projeto permitiu praticar um fluxo completo de desenvolvimento utilizando Git e GitHub, desde a criação da estrutura e desenvolvimento em branches até Pull Request, resolução de conflitos, documentação e publicação da versão final na branch `main`.
